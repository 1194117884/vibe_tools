Game Position Matrix 游戏定位矩阵系统

用一张动态矩阵管理游戏定位：每一行代表一个游戏、竞品、版本分支或微调方案。 目标不是“记功能”，而是看清楚：它服务谁、靠什么留存、差异打在哪、改动是否偏离主线。

筛选与数据

0当前行数
0平均开发难度
0平均粘性
0变更方案

使用方式：点表格任意行可编辑；勾选两行后点“对比选中两行”；复制一行可以做版本微调。 所有数据会自动保存到浏览器 localStorage。

评分口径

  • 入门门槛：1 打开即懂，5 需要学习成本。
  • 深度上限：1 很快玩腻，5 高手可长期研究。
  • 粘性：1 偶尔玩，5 每日/社交/成长驱动强。
  • 开发难度：1 很轻，5 多系统/多平台/强运营。
